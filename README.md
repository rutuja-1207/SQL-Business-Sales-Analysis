# 📊 SQL Business Sales Analysis

## 📌 Project Overview

This project analyzes customer, product, and sales data using SQL.

The objective is to identify business insights related to customer behavior, product performance, sales trends, and revenue generation.

---

## 🎯 Business Problem

Businesses generate large amounts of sales data every day.

This project helps answer questions like:

- Who are the top customers?
- Which products generate the highest revenue?
- Which cities perform best?
- How do sales change over time?

---

## 🛠 Tools Used

- PostgreSQL
- pgAdmin 4
- SQL

---

## 🗂 Database

Three tables were used:

- Customers
- Products
- Orders

Relationships were created using Primary Key and Foreign Key.
